# 高一语文教学设计

> 高一语文（统编版必修上/下册）课文与单元教学设计，输出教学目标、重难点、课时安排、情境任务链、课堂活动、板书设计与分层作业。

## 功能

输入篇目名或单元，输出：

1. 教学定位
2. 教学目标（3 条，分素养维度，用可观测行为动词）
3. 教学重难点
4. 课时安排表（总时长误差为 0）
5. 情境任务链（一个大情境 + 2~4 个递进子任务）
6. 主问题设计（1 个核心主问题 + 2~3 个追问链）
7. 板书设计（ASCII 框图）
8. 分层作业（基础/提高/拓展）
9. 教学预设与应对

## 内置对照表

含**统编版必修上册、必修下册全部 16 个单元**的人文主题、学习任务群、核心篇目对照表。

## 质量标准

- **目标可检测**：每条目标含"学生能……"的可观测行为，禁止"培养学生的……情怀"
- **主问题唯一**：一节课只有一个主问题，其余一律是追问
- **情境真实**：来自学生真实生活或真实社会场景，禁止"假如你是某某古人"这类伪情境
- **不超纲**：高一不提前上选择性必修内容
- **引用准确**：拿不准的原文标注"请核对教材"
- **时间闭合**：各环节时长之和等于课时总时长

## 默认参数

- **教材**：统编版《高中语文》必修上册 / 必修下册
- **学情分层**：重点校 / 普通校 / 薄弱校，未说明时按普通校处理
- **课时**：1 课时 = 45 分钟

## 常见坑

- 把"单元导语"抄一遍当教学目标
- 情境任务与文本解读两张皮，活动结束学生没多读懂一点文本
- 活动热闹但无语文内核（如为《祝福》排课本剧却不分析叙述视角）
- 作业三档其实难度一样，只换了篇目

## 安装

```bash
git clone https://github.com/zhshy/gaoyi-chinese-lesson-design.git
```

将技能目录放入 WorkBuddy 的用户级技能目录：

- **Windows**：`C:\Users\<用户名>\.workbuddy\skills\`
- **macOS / Linux**：`~/.workbuddy/skills/`

重启 WorkBuddy 后生效。

## 什么是 Skill

Skill 是给 AI 助手加载的专业知识包：一个 `SKILL.md` 定义触发条件与工作流程，`references/` 存放按需加载的细节文件。加载后助手会按既定流程工作，而不是即兴发挥。

本仓库技能遵循 Agent Skills 规范：YAML frontmatter + Markdown 正文 + 渐进式披露的 references。
