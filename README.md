# 语文教学设计

> 统编版高中语文（必修上/下册 + 选择性必修上/中/下册）课文与单元教学设计，输出教学目标、重难点、课时安排、情境任务链、课堂活动、板书设计与分层作业，并默认配一份 20 页以内、上课投给学生看的课件 PPT（含一页作者介绍；配图用影像蒸馏生成）。

## 功能

输入篇目名或单元，输出：

1. 教学定位
2. 教学目标（3 条，分素养维度，用可观测行为动词）
3. 教学重难点
4. 课时安排表（总时长误差为 0）
5. 情境任务链（一个大情境 + 2~4 个递进子任务）
6. 主问题设计（1 个核心主问题 + 2~3 个追问链）
7. 板书设计（ASCII 框图）
8. 分层作业（基础/提高/拓展）
9. 教学预设与应对
10. 配套课件 PPT（20 页以内，默认课件版：上课投给学生看，含一页作者介绍、配图用影像蒸馏生成）

## 配套课件 PPT 标准

PPT 为默认交付物，20 页以内（含标题页、作者介绍页与小结页）。七条硬标准：

1. 页数 ≤ 20 页，含标题页、作者介绍页与小结页
2. 台下 5 秒内能看清全页——做不到就精简或分页，不许缩字号
3. 底色干净不花哨，四周留白 5%–10%
4. 正文 ≥ 18pt，目标 22pt
5. 先定页内容，再谈美化（两阶段不可颠倒）
6. 标题样式全篇统一
7. 配图用影像蒸馏生成，插在留白充足的页面（每份 3–5 张，同一视觉系统）

作者介绍页为固定页：只保留能进入文本理解的 1–2 个信息点，不做生平年表。

### 配图：影像蒸馏

课件配图一律用**影像蒸馏**生成（参照 `Zeejay0/gathered-scenes-zine-skill` 的 `scene-distillation-zine-v1-3`），不使用写实照片与图库素材。

- **源**：以课文的景物描写文字为源（原技法以实拍照片为源，此处为文本驱动的适配）。
- **流程**：文本蒸馏卡 → 表达命题 → 中心张力 → 视觉隐喻 → 形式落地 → 解释性开口。
- **语法**：编辑式抽象，删去约 65–90% 描述性细节，纸面留白 68–85%，只留一个高彩强调色。
- **位置**：插在留白充足的页面（情境导入页、作者介绍页等），每份 3–5 张，做有边界的图块，不铺满当背景。
- **作者形象**：写意化（剪影、纸雕式），标注"示意图"，不得做成写实照片。
- **判据**：说不出配图对应课文哪一句，就删掉。

详见 `SKILL.md` 的「配套 PPT 交付标准」一节。

## 质量标准

- **目标可检测**：每条目标含"学生能……"的可观测行为，禁止"培养学生的……情怀"
- **主问题唯一**：一节课只有一个主问题，其余一律是追问
- **情境真实**：来自学生真实生活或真实社会场景，禁止"假如你是某某古人"这类伪情境
- **不超纲**：必修备课不提前上选择性必修内容
- **引用准确**：拿不准的原文标注"请核对教材"
- **版本先核对**：动手前确认册次与印次
- **时间闭合**：各环节时长之和等于课时总时长

## 默认参数

- **教材**：统编版《高中语文》必修上册 / 下册、选择性必修上册 / 中册 / 下册
- **学情分层**：重点校 / 普通校 / 薄弱校，未说明时按普通校处理
- **课时**：1 课时 = 45 分钟

## 常见坑

- 把"单元导语"抄一遍当教学目标
- 情境任务与文本解读两张皮，活动结束学生没多读懂一点文本
- 活动热闹但无语文内核（如为《祝福》排课本剧却不分析叙述视角）
- 作业三档其实难度一样，只换了篇目
- 课件里出现教学目标、设计意图——那是给听课教师看的，不是给学生看的
- 作者介绍页写成生平年表，只留与文本理解相关的信息点
- 配图用写实照片或图库素材，与课件的纸面墨色体系冲突
- 配图与文本两张皮：说不出它对应课文哪一句，就是装饰而非教学材料
- 把配图铺满整页当背景，文字压在图上看不清
- 作者形象做成写实照片——历史人物无可靠照片，写实化会让学生误当史实

## 安装

```bash
git clone https://github.com/zhshy/chinese-lesson-design.git
```

将技能目录放入 WorkBuddy 的用户级技能目录：

- **Windows**：`C:\Users\<用户名>\.workbuddy\skills\`
- **macOS / Linux**：`~/.workbuddy/skills/`

重启 WorkBuddy 后生效。

## 版本与更新

- **版本号**遵循语义化版本，写在 [`SKILL.md`](SKILL.md) 的 frontmatter `version:` 字段；**每个版本对应一个 git 标签**（`v1.0.0` …），逐版变更见 [`CHANGELOG.md`](CHANGELOG.md)。
- **版本号含义**：主版本＝目录结构或不兼容的输出格式改动；次版本＝新增能力（新增栏目、新增课件标准条目、新增册次）；修订版＝文字订正与口径微调。
- **按版本安装**（可复现的取版方式）：

```bash
# 取指定版本
git clone --branch v1.6.0 --depth 1 https://github.com/zhshy/chinese-lesson-design.git
# 不装 git，也可直接取该版本的 tar 包
curl -LO https://codeload.github.com/zhshy/chinese-lesson-design/tar.gz/refs/tags/v1.6.0
```

- **核对手上副本的版本**：装进 `~/.workbuddy/skills/` 的副本不带 `.git`，看 [`SKILL.md`](SKILL.md) 前几行的 `version:` 字段即为当前版本；若取的是 git 检出，用 `git -C <repo> describe --tags`。

## 什么是 Skill

Skill 是给 AI 助手加载的专业知识包：一个 `SKILL.md` 定义触发条件与工作流程，`references/` 存放按需加载的细节文件。加载后助手会按既定流程工作，而不是即兴发挥。

本仓库技能遵循 Agent Skills 规范：YAML frontmatter + Markdown 正文 + 渐进式披露的 references。
